# Скриншоты для отчёта

Делай скриншоты при собственном выполнении шагов. Здесь нет утверждения, что VPN уже настроен.

| № | Что показать | Что подтверждает |
|---|---|---|
| 01 | `java -version` и `./gradlew --version` | Java 21 и Gradle |
| 02 | Структура проекта и `build.gradle` в IDEA | Java / Spring Boot 4 / Groovy DSL |
| 03 | `docker compose ps` | Работа PostgreSQL и Keycloak |
| 04 | Главная страница | Первая страница приложения |
| 05 | Настройки клиента shelf-web в Keycloak: Standard flow и точный Redirect URI | Настройка OAuth-клиента |
| 06 | Переход на `/shelf` в приватном окне до входа | Защита страницы |
| 07 | Страница входа Keycloak | Внешний сервер авторизации |
| 08 | Моя полка с тремя записями разных категорий | Работа многостраничного приложения |
| 09 | Создание записи и редактирование статуса | Работа с данными |
| 10 | Профиль пользователя | Получение имени и email через OIDC |
| 11 | Пустая полка второго пользователя | Изоляция данных между аккаунтами |
| 12 | `./gradlew test` с BUILD SUCCESSFUL | Автоматические проверки |
| 13–16 | Настройка WireGuard, handshake, доступ с VPN, отсутствие доступа без VPN | Отдельный этап настройки VPN |

Не снимай .env, .local/credentials.txt, приватные ключи WireGuard, содержимое cookie, access/refresh/ID-токены и адресную строку OAuth callback с временным кодом. В настройках Keycloak вкладка Credentials не нужна.

## Пример данных для демонстрации

1. «Понедельник начинается в субботу» — книга, в планах, «Посоветовали друзья».
2. «Прибытие» — фильм, завершено, «Пересмотреть ради деталей».
3. «Portal 2» — игра, в процессе, «Продолжить на выходных».

Эти записи нужно создать через интерфейс: они не добавляются автоматически.
